# BMI AI 体重管理（离线简化版）

一款无需服务器、云开发或数据库的微信原生小程序。所有健康档案与记录只存储在当前设备的微信本地缓存中，因此不产生后端费用。

## 核心能力

- 健康建档：身高、体重、年龄、性别、活动水平；自动计算 BMI、BMR、TDEE 和建议热量。
- 目标与记录：减脂/维持/增肌目标、体重、围度、饮食和运动记录。
- 本地趋势与周报：7/30/90 日体重趋势、饮食/运动统计、打卡和成就。
- 食谱与训练：内置精选食谱、收藏、菜单和训练计划。
- 离线健康助手：基于本地规则给出饮食、运动、睡眠和体重波动建议，不调用付费 AI 服务。
- 联网营养查询：食物热量查询优先请求 Open Food Facts 开放营养数据库（权威、免费、无需密钥），显示数据来源与更新时间；断网或请求失败时自动回退本地食物库，不影响助手其它功能。
- 数据管理：在设置页导出或清空本地数据（如安装包中该页已启用）。

> 健康建议仅供日常健康管理参考，不能替代医生的诊断、治疗或处方。联网查询的营养数据来自第三方开放数据库，数值可能因产品/批次存在差异，仅供参考，不构成医疗建议。

## 项目结构

与 [health-recipe](https://github.com/sssong-sr/health-recipe) 保持同类目录组织：

```text
miniprogram/              # 微信小程序前端
  behaviors/              # 页面共用行为
  pages/                  # 按功能拆分的页面
  components/             # 可复用展示组件
  utils/                  # 健康计算、本地仓储、内置食物数据
  static/                 # 静态资源
scripts/                  # 本地检查脚本
project.config.json       # 微信开发者工具项目配置
```

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择“导入项目”。
2. 选择克隆后的仓库根目录（包含 `project.config.json`）。
3. 仓库使用示例 AppID `touristappid`。如需使用自己的 AppID，请在微信开发者工具导入时选择，或在本地将 `project.config.json` 中的 `appid` 和 `appId` 改为一致的实际值；请勿把个人配置提交到仓库。
4. 不必开通云开发或部署云函数。
5. 点击编译。首次进入完成建档后，所有数据将保存到当前微信客户端。

## 联网营养查询的域名配置

食物热量查询会通过 `wx.request` 访问 Open Food Facts 开放营养数据库：

```
https://world.openfoodfacts.org
```

- **开发调试**：本项目 `project.config.json` 已设置 `"urlCheck": false`，开发者工具默认不校验合法域名，可直接联网。
- **正式发布**：需在微信公众平台「开发 → 开发管理 → 开发设置 → 服务器域名 → request 合法域名」中把 `https://world.openfoodfacts.org` 加入白名单，否则正式版会被微信拦截（网络请求失败时仍会回退本地食物库，不影响助手其它功能）。
- 请求超时见 `miniprogram/app.json` 的 `networkTimeout.request`（15000ms），联网查询内部超时 8 秒，失败即回退本地数据。

## 可选联网健康搜索回退（默认关闭）

助手回答以本地规则为主；如需联网权威来源，可自行部署一个 HTTPS 服务端代理来调用微软官方 Bing Web Search API，再由客户端访问该代理。**这项能力默认关闭**，不配置即安全回退本地规则，不会伪造联网结果。

**为什么需要服务端代理**：Bing API 的订阅密钥必须保存在你的服务器端，绝不能下发给小程序客户端；同时客户端不直接抓取 `bing.com` 网页。本工程没有自有后端，因此只有在你部署代理后才可用。

1. 部署一个服务端函数（如云函数 / 网关函数），调用 Bing Web Search API `v7/cognitive/search`（`q=用户查询词`，`setLang=zh-hans`），把密钥放在服务端环境变量。
2. 服务端对结果按权威来源过滤后，返回如下 JSON：
   ```json
   { "sources": [ { "title": "标题", "url": "https://…", "domain": "www.who.int", "snippet": "摘要" } ] }
   ```
3. 在小程序内写入本地配置（本工程不提供写入口，仅供开发者调试），键 `bmi_search_cfg`：
   ```json
   { "enabled": true, "proxyUrl": "https://你的域名/health-search" }
   ```
4. 正式发布时把该代理域名加入微信「request 合法域名」白名单。

客户端逻辑见 `miniprogram/utils/online-health-search.js`：请求超时（6 秒）、未配置、或来源不在权威白名单（WHO / 各国疾控 / 政府 / 主要医疗机构等）时一律返回 `null`，助手立即回退本地规则。**无论是否联网，本应用都不用于医疗诊断。**

## 数据与隐私

- 本项目没有自有网络后端、账号同步或远端数据库。
- 唯一默认网络请求为食物热量查询时向 Open Food Facts 开放营养库发起的关键词搜索，仅发送用户输入的查询词；不上传任何健康档案数据。
- 联网健康搜索仅在开发者自行部署并显式开启上述代理时才生效；你自行决定是否开启。
- 清除微信缓存、卸载小程序或更换设备可能导致本地数据丢失；请在设置页（如可用）导出备份。
- 本地数据只应由设备持有人使用；请勿将本应用用于医疗诊断。

## 算法

- BMI：`体重(kg) / 身高(m)²`
- BMR：Mifflin–St Jeor 公式
- TDEE：`BMR × 活动系数`
- 建议热量：减脂取 TDEE 的约 82.5%，增肌取约 112.5%，维持取 TDEE。
